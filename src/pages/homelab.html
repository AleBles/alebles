Homelab

Self-hosted, privacy-first home infrastructure. A low-power x86 server and NAS run everything on the local network; management is web-UI first, data stays on hardware I own.

Running: ad-blocking DNS, VPN, reverse proxy with TLS. Home Assistant with fully local voice (STT/TTS), Z-Wave, MQTT. Local LLM for natural-language home queries. Self-hosted photos and media. IP cameras with on-device object detection. Stack-wide monitoring and alerts.

Local-first. If it can run at home, it does. Maintainable by one person, resilient enough to be boring, private by default.
